# Educational-SDB
helloooooo this is a repository for my first semester project in my robotics course -- an educational, inert model of a small diameter bomb.

**What is in this repository?**
- There's an stl file, depicting how the SDB was completely fabricated on CAD.
- 2 arduino IDE files (*.ino) -> one for the fin movement and another for sensor data.
- 2 *.mp4 files showing fin movement of the actuator bay separated and the fin movement on the final SDB.
- finally, a *.png file which shows the electronic components used in the circuit of the sdb.

**Now what is an SDB?**

The acronym SDB stands for **S**mall **D**iameter **B**omb. It is an autonomous munition with high accuracy and precision when it comes to attacking targets. It prevents **collateral damage** which basically means damage towards unwanted targets. It can even target dynamic targets! Which is way better in comparison to using 1000-2000lbs of static explosives like dynamites, grenades and other such traditional bombs.
